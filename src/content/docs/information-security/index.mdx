Security is about keeping systems and data **confidential**, **intact** and **available** against an adversary. This course starts with the goals, threats and access-control models, works through classical ciphers to modern symmetric ciphers (DES, AES) and how to use them (modes of operation), then public-key cryptography (RSA, Diffie–Hellman, ElGamal, elliptic curves), hashes, MACs, digital signatures and certificates. It ends with how these pieces protect real systems: authentication, TLS, IPsec, firewalls, and common attacks on software and the web. The number theory behind RSA is in [Discrete Mathematics](/discrete-mathematics/number-theory/).
