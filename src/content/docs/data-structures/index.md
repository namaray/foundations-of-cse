A **data structure** is a way of organising data so that the operations you need are efficient. Choosing one is always a trade-off between speed, memory and simplicity. This course is the foundation for [Algorithms](/algorithms/), and it is the most-asked subject in lecturer vivas and master's admission tests.

## Study path

Work through the pages in order. Each one covers the definition, how it works with a worked example, its costs, and typical viva questions with answers you can reveal.

- [ ] [Complexity analysis](/data-structures/complexity-analysis/): Big-O, Ω and Θ, growth rates, amortized analysis
- [ ] [Arrays](/data-structures/arrays/): address calculation, dynamic arrays, sparse matrices
- [ ] [Linked lists](/data-structures/linked-lists/): singly, doubly and circular lists, reversal, cycle detection
- [ ] [Stacks](/data-structures/stacks/): balanced brackets, infix to postfix, postfix evaluation
- [ ] [Queues](/data-structures/queues/): circular queues, deques, priority queues
- [ ] [Hashing](/data-structures/hashing/): hash functions, chaining, open addressing, rehashing
- [ ] [Trees & BSTs](/data-structures/trees-and-bst/): binary tree properties, traversals, BST operations
- [ ] [Balanced trees](/data-structures/balanced-trees/): AVL rotations, red–black trees, B-trees and B+ trees
- [ ] [Heaps](/data-structures/heaps/): sift up and down, building a heap in $O(n)$, heapsort
- [ ] [Graphs](/data-structures/graphs/): adjacency matrix vs list, BFS, DFS, topological sort
- [ ] [Disjoint set union](/data-structures/disjoint-set/): union by rank, path compression
- [ ] [Tries, segment trees & Fenwick trees](/data-structures/tries-and-range-trees/)

Then revise with the **[cheat sheet](/data-structures/cheat-sheet/)**.

## Standard textbooks

- Seymour Lipschutz: *Data Structures* (Schaum’s Outline)
- Cormen, Leiserson, Rivest & Stein: *Introduction to Algorithms* (CLRS), Parts III and V
