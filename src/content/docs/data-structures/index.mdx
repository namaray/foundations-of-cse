A **data structure** is a way of organising data so that the operations you need are efficient. Choosing one is always a trade-off between speed, memory and simplicity. This course starts with how to measure cost, moves through linear structures (arrays, lists, stacks, queues), then hashing and trees, and ends with graphs and a few specialised structures. It is the foundation for [Algorithms](/algorithms/), and the most-asked subject in lecturer vivas and master's admission tests.
