Machine learning builds programs that improve from **data** instead of being explicitly programmed. This course covers the main ideas (generalisation, overfitting, the bias–variance trade-off), the classic models (regression, k-NN, naive Bayes, decision trees, SVMs, clustering, PCA), how to evaluate them honestly, and neural networks up to modern deep learning.
