Digital logic is how hardware computes with 0s and 1s. The course builds from number representations and logic gates, through circuits whose output depends only on their inputs (combinational), to circuits with memory (sequential), ending with finite state machines and memory chips. It is the foundation for [Computer Architecture](/computer-architecture/).
