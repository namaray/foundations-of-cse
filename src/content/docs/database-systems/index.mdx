A database system stores data so that many users can query and update it correctly, quickly and safely, even when things crash. The course moves from design (ER diagrams, normalization) through querying (relational algebra, SQL) to the internals that make it all work (indexes, transactions, recovery).

Most examples use one small university schema:

- **Student**(<u>sid</u>, name, dept, cgpa)
- **Course**(<u>cid</u>, title, credits, dept)
- **Enrolled**(<u>sid</u>, <u>cid</u>, grade)
