Object-oriented programming organises a program around **objects** that bundle data with the operations on it. This course covers the core ideas (classes, encapsulation, inheritance, polymorphism, abstraction) with examples in both **C++** and **Java**, then exceptions, generics and the design principles used in real software. Viva boards ask about these concepts constantly, usually with "give an example".

## Standard textbooks

- Bjarne Stroustrup: *Programming: Principles and Practice Using C++*
- Herbert Schildt: *Java: The Complete Reference*
- E. Balagurusamy: *Object-Oriented Programming with C++*
- Gamma, Helm, Johnson & Vlissides: *Design Patterns* (the "Gang of Four")
