## 1. The 8253/8254 programmable interval timer

Three independent **16-bit down counters**. Each has a clock input (CLK), a gate input (GATE, which enables counting) and an output (OUT). The CPU loads a count, the counter decrements on each clock pulse, and OUT changes according to the **mode**.

| Mode | Name | Output |
|---|---|---|
| 0 | Interrupt on terminal count | Goes high when the count reaches 0 (one interrupt after a delay) |
| 1 | Hardware-retriggerable one-shot | A low pulse of programmable length, started by GATE |
| 2 | Rate generator | A short pulse every $N$ clocks (a divide-by-$N$ counter) |
| **3** | **Square-wave generator** | A square wave with period $N$ clocks |
| 4 | Software-triggered strobe | One pulse after the count expires |
| 5 | Hardware-triggered strobe | Like mode 4, but started by GATE |

**Choosing the count:**

$$
N = \frac{f_{\text{clock}}}{f_{\text{output}}}
$$

**Example.** With a 1.19318 MHz input clock (the PC's timer clock), a 1 kHz square wave needs $N \approx 1193$ in mode 3.

The maximum count is 65,536 (loaded as 0). Longer delays come from **cascading** counters: the output of one clocks the next.

Uses: real-time clock interrupts, delays, baud-rate generation, and sound (the PC speaker).

The 8254 is an improved, faster 8253 with a read-back command for checking status.

## 2. The 8237 DMA controller

The **8237** performs [direct memory access](/computer-architecture/input-output/#4-direct-memory-access-dma) for up to **4 channels** (cascadable). The CPU programs each channel's starting address, byte count and mode; the 8237 then requests the bus (HOLD), the CPU grants it (HLDA), and the 8237 moves data directly between the device and memory.

Modes: single transfer, block transfer, demand transfer, and cascade. In the original IBM PC it handled the floppy disk and memory refresh.

## 3. The 8251 USART

The **8251** (universal synchronous/asynchronous receiver-transmitter) converts between the CPU's parallel bytes and serial bit streams:

- **Asynchronous** mode: each character is framed by a **start bit** and one or more **stop bits**, with optional parity. Common for serial ports (RS-232).
- **Synchronous** mode: characters flow continuously after sync characters, timed by a shared clock.

The **baud rate** comes from an external clock, often generated by an 8254 counter. With 1 start bit, 8 data bits and 1 stop bit, each character takes 10 bit times, so 9600 baud carries 960 characters per second.

## 4. Microprocessors and microcontrollers

| | Microprocessor | Microcontroller |
|---|---|---|
| On the chip | CPU only | CPU **plus** RAM, ROM/flash, I/O ports, timers, serial interfaces, ADC |
| External parts needed | Memory and peripheral chips | Few or none |
| Typical architecture | Von Neumann | Often **Harvard** (separate program and data memory) |
| Goal | Raw performance, general purpose | Low cost and power, a dedicated task |
| Examples | 8086, Intel Core, Apple M-series | 8051, AVR (Arduino), PIC, ARM Cortex-M |
| Used in | PCs, servers | Appliances, cars, toys, sensors, embedded systems |

## 5. The 8051 microcontroller

| Feature | 8051 |
|---|---|
| CPU | 8-bit |
| On-chip program memory | 4 KB ROM |
| On-chip data memory | 128 bytes RAM (including 4 register banks of R0–R7) |
| I/O | **4 ports** (P0–P3), 8 bits each, 32 I/O lines |
| Timers | 2 16-bit timers/counters |
| Serial | 1 full-duplex UART |
| Interrupts | 5 sources (2 external, 2 timer, 1 serial) |
| Addressing | 64 KB external program memory and 64 KB external data memory |

It has a **bit-addressable** area of RAM and special function registers, so single I/O pins and flags can be set and tested directly (`SETB P1.0`, `JB P3.2, label`), which suits control tasks.

## 6. Modern microcontrollers

- **AVR** (for example, the ATmega328 in the Arduino Uno): an 8-bit RISC with flash memory; programmed in C, very popular for learning and prototyping.
- **ARM Cortex-M** (STM32, nRF and many others): 32-bit, low-power cores with a nested vectored interrupt controller; the standard for modern embedded and IoT devices.
- **ESP32**: a microcontroller with built-in Wi-Fi and Bluetooth.

Common on-chip peripherals: GPIO pins, timers and PWM (for motor and LED control), ADC and DAC, UART, SPI and I²C serial buses, and watchdog timers.

## Summary

- The 8254 has three 16-bit counters with six modes; count $N = f_{\text{clock}} / f_{\text{out}}$; mode 3 makes square waves.
- The 8237 moves data by DMA on 4 channels, taking the bus with HOLD/HLDA.
- The 8251 USART converts parallel data to serial (asynchronous with start and stop bits, or synchronous).
- A microcontroller integrates CPU, memory and peripherals for dedicated low-cost tasks; the 8051 has 4 KB ROM, 128 B RAM, 4 ports, 2 timers and a UART.

## Check yourself

<details>
<summary>An 8254 counter is clocked at 2 MHz. What count gives a 500 Hz square wave?</summary>

$N = 2{,}000{,}000 / 500 = 4000$, in mode 3.
</details>

<details>
<summary>Why are microcontrollers often built with a Harvard architecture?</summary>

Program and data can be fetched at the same time over separate buses, and program code can live in flash while data uses RAM, which suits small, fixed-purpose systems.
</details>

<details>
<summary>How many characters per second does a 19200-baud link carry with 8 data bits, no parity and 1 stop bit?</summary>

Each character takes 1 + 8 + 1 = 10 bits, so 19200 / 10 = 1920 characters per second.
</details>
