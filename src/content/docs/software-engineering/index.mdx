Software engineering is the discipline of building software that works, on time and within budget, and that can be maintained for years by people who did not write it. This course covers how teams organise their work (process models, Agile), what they build (requirements, modelling, design), how they check it (testing), and how they run projects (estimation, scheduling, quality).
